## 📖 碩士論文
* **測量誤差資料下懲罰式線性迴歸模型之延伸校正分數法與變數選取**
* 聚焦於解決高維度與共線性資料環境下的異質性測量誤差問題。為避免實務數據在多元線性迴歸中，因測量誤差導致估計偏誤與變數挑選失準，本研究應用延伸校正分數法，並進一步導入嶺迴歸 (Ridge) 懲罰項，以兩階段的分析流程以兼顧變數挑選與參數估計。透過 R 語言設計涵蓋不同樣本數與誤差程度之模擬實驗，結果證實採用兩階段懲罰項之 ECS 模型，能有效提升高維度數據下的數值穩定性與估計準確度，為實務研究者提供處理測量誤差數據之穩健策略。
